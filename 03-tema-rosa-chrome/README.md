# 🌸 Nova Guia Rosa para Chrome

## 💡 O problema

Eu queria personalizar a página de nova guia do Chrome para que ela combinasse com a identidade visual que uso no meu ambiente de trabalho, substituindo a aparência padrão por uma interface própria em preto e rosa.

## 🤖 Como usei IA

Usei IA como apoio durante a construção da solução, transformando a ideia visual em uma implementação funcional. O processo foi iterativo: defini o resultado desejado, gerei e ajustei a estrutura necessária, testei diretamente no Chrome e refinei os elementos que não correspondiam ao resultado esperado.

## 🛠️ Solução

Foi criada uma personalização da página de nova guia utilizando HTML e CSS, carregada no Chrome por meio de um `manifest.json`. A interface mantém as funções necessárias para uma nova guia enquanto aplica a identidade visual escolhida.

## 👩‍💻 Minha participação

Defini o objetivo e a identidade visual, conduzi as instruções fornecidas à IA, testei a implementação no navegador e identifiquei os pontos que precisavam de ajustes. A solução foi refinada a partir dos testes até que o comportamento e a aparência correspondessem ao resultado desejado.

## 📁 Arquivos

- [`manifest.json`](./manifest.json) — configuração utilizada pelo Chrome.
- [`nova-guia.html`](./nova-guia.html) — estrutura da página personalizada.
- [`style.css`](./style.css) — estilos e identidade visual da interface.
