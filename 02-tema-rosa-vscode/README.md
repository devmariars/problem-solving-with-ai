# 🎨 Tema Rosa Personalizado para VS Code


## 💡 O problema
Eu queria personalizar meu ambiente de desenvolvimento para que ele tivesse mais identidade e combinasse com o meu estilo visual, sem prejudicar a legibilidade do código ou a usabilidade do VS Code.

## 🤖 Como usei IA
Usei IA como apoio para transformar a ideia visual em configurações aplicáveis ao VS Code. A solução foi construída de forma iterativa: descrevi o resultado desejado, testei as configurações geradas, identifiquei elementos que ainda não correspondiam ao visual esperado e refinei as instruções até chegar ao resultado final.

## 🛠️ Solução
Foi criado um conjunto de configurações em JSON para personalizar a interface do VS Code, incluindo cores de fundo, abas, barra lateral, terminal, editor e outros elementos visuais. O resultado mantém a funcionalidade do ambiente de desenvolvimento enquanto aplica a identidade visual rosa desejada.

## 👩‍💻 Minha participação
Defini o objetivo visual, descrevi os requisitos para a IA, testei as configurações no ambiente real e avaliei o resultado a cada alteração. Durante os testes, identifiquei diferenças entre o resultado gerado e o esperado e refinei as instruções até alcançar a personalização desejada.


## 📁 Arquivo

As configurações utilizadas estão disponíveis no arquivo [`settings.json`](./settings.json).

## ✨ Resultado
O ambiente final ficou totalmente personalizado em tons de rosa, mantendo contraste e legibilidade para uso durante a programação.
